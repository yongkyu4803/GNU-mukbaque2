# Local font assets

- `KIMM_Bold.ttf`: copied from the user's installed 기계연구원 font. The font name table identifies the family as `KIMMBold`, copyright 2021 FONTLAB Co., Ltd. The file is unchanged. Official project: https://www.kimm.re.kr/
- `Pretendard-Regular.woff2`, `Pretendard-SemiBold.woff2`: Pretendard 1.3.9, downloaded from the official project's distribution. SIL Open Font License 1.1 is retained in `Pretendard-LICENSE.txt`. Source: https://github.com/orioncactus/pretendard/tree/v1.3.9

All fonts are self-hosted. Rendering does not require a font CDN or transmit research data.
